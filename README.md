# Password Strength Checker

A tool that checks password strength in real time and gives clear feedback on what's missing — built to mimic the kind of checks real login systems use to enforce secure passwords.

**Live demo:** https://brandnwp01.github.io/password-strength-checker/

## What it checks
- Length (8–16 characters)
- Uppercase and lowercase letters
- At least one number
- At least one special character

## Python version
`password_checker.py` — a terminal script version. Enter a password and get feedback in a loop until it passes all checks.

## Web version
A browser-based version with a custom-styled interface (HTML, CSS, JS). Includes a show/hide password toggle and instant feedback when you click Check — same logic as the Python version, translated to run live in the browser.
