# Password Strength Checker

A tool that checks password strength and gives feedback on how to improve it. Built two ways: a Python terminal script and a live styled webpage.

## What it checks
- Length (8–16 characters)
- Uppercase and lowercase letters
- At least one number
- At least one special character

## Python version
Run `password_checker.py` in a terminal. Enter a password and get feedback until you enter one that passes all checks.

## Web version
A browser-based version with a custom-styled interface (HTML, CSS, JS) — same checks as the Python version, with a show/hide password toggle and live feedback when you click Check.
